# Making Requests in the Meeting

## Core Vocab & Phrases（核心词汇与短语）

### Request-related（请求相关）

request（请求）, ask for（请求）, need（需要）, require（需要，较正式）替换词：ask for a favor（请求帮忙）, seek assistance（寻求协助）, request support（请求支持

### Meeting-related（会议相关）

meeting（会议）, scrum（站会）, discussion（讨论）, agenda（议程）, time（时间）替换词：session（会议场次）, daily standup（每日站会）, talk-through（讨论）

### Request-related（请求相关）

Help（帮助）, please（请）, could（能，委婉）, explain（解释）；替换词：Assist（帮助）, kindly（请，委婉）, can（能）, clarify（说明）

## Expression Phrases（表达短语）

Excuse me, can you help me?（打扰一下，你能帮我吗？）, I’d like to ask you to...（我想请你……）, Could you explain it again?（你能再解释一遍吗？）；替换词：Sorry to interrupt, can you help me?（抱歉打扰，你能帮我吗？）, I want to ask you to...（我想请你……）, Can you clarify it again?（你能再说明一遍吗？）
